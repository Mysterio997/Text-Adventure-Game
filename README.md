For this project I have been assigned with a brief to make a terminal Text Adventure Game, this game must include 4 different places the player can travel, a number input, Input Error Handling / Validation and finally one way to win and lose. Halloween themed task and my game is based around being trapped within a Curry's overnight after a hectic Black-Friday-Sale.
